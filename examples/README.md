# 免费查看一个样例 / Free first look

```sh
python3 examples/try_retrieval.py --destination ../mcm-sample
```

只用 Python 标准库，执行实际 Retriever 的多路合并、去重和排序，并生成可查引用的 Markdown。内容自制，明确为合成材料；嵌入向量和存储是固定替身，修改清单为人工样例，不证明语义召回或 LLM 诊断效果。No API calls or model downloads.

打开输出目录中的 `sample-report.md` 和 `retrieval.json` 对照引用。完整 PDF 分析仍按 README 配置模型和自备合法论文。
